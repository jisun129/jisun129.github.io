Clinical Code Prediction from Longitudinal Notes

Combining discharge and radiology notes over time to predict ICD and CPT codes.

Completed
Context
University of Minnesota · Academic project
Role
Academic project
Period
Graduate study

The question

A single clinical document captures only part of a patient’s history. This project explored whether combining discharge and radiology notes in chronological order could improve clinical code prediction.

My approach

  • Used BioClinicalBERT to represent the text of discharge and radiology notes.
  • Modeled the sequence of note representations with an LSTM to incorporate longitudinal context.
  • Compared longitudinal modeling with a single-document approach and examined performance on less frequent labels.

What came out of it

Longitudinal note modeling improved performance over a single-document approach, while rare-label prediction remained a challenge. No numerical performance claim is included here because an exact metric has not been supplied.

Perspective

The project motivated my interest in multimodal clinical modeling, imbalanced labels, and the reliability of models when some clinical information is missing.
